# excalidraw-local

A local whiteboard for drawing and writing, built with Odin and raylib.

## Build

```sh
./build.sh
./build/excalidraw-local [board.json]
```

Open the menu left of the toolbar to create, open or save boards. Drop a `.json` file on the window to open it.

## Shortcuts

| Key | Action |
|---|---|
| `V` `1` | Select |
| `R` `2` | Rectangle |
| `O` `3` | Ellipse |
| `A` `4` | Arrow |
| `L` `5` | Line |
| `P` `6` | Freehand |
| `T` `7` | Text |
| `Esc` | Deselect, finish text or cancel drawing |
| `Ctrl+N` | New board |
| `Ctrl+O` | Open |
| `Ctrl+S` | Save |
| `Ctrl+Shift+S` | Save as |
| `Ctrl+Z` / `Ctrl+Shift+Z` | Undo / Redo |
| `Delete` | Delete selection |
| Wheel | Zoom |
| `Space`+drag, middle drag | Pan |
